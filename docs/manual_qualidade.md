## 2. Boas Práticas Aplicadas

- Versionamento com Git (commits organizados e mensagens claras)

- Python 3.12
- Pytest
- Git + GitHub
- GitHub Actions (CI)

## 4. Como Executar os Testes Localmente

```bash
pip install -r requirements.txt
set PYTHONPATH=.
pytest

```
